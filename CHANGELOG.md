# Aspia (форк без 2FA) — что изменено

Основа: оригинальная Aspia 3.0.37. Ниже перечислено, чем этот форк отличается от неё.
Версия сборки — `3.0.37.<номер коммита>`.

## Аутентификация и хосты

- Удалена двухфакторная аутентификация: вход выполняется по логину и паролю.
- Новые хосты подтверждаются автоматически, настройка и страница «Неподтверждённые хосты» удалены.
- Одноразовый пароль можно отключить. При отключённом пароле его поле скрыто в окне хоста.
- Хост получает постоянный ID сразу; освободившиеся ID переиспользуются (берётся минимальный
  свободный). У хостов появилась дата создания.
- Legacy-слой принимает хосты версии 2.4.

## Терминал

- Оболочка выбирается по версии системы: ConPTY (Windows 10 1809 и новее) — PowerShell, без ConPTY
  (Windows 7/8) — перенаправленные каналы, PowerShell на 8+ и cmd.exe на 7.
- Агент терминала запускается с повышенным токеном без запроса UAC.
- Ошибка запуска оболочки показывается в окне терминала, а не молча.
- Исправлено окно терминала: размер, положение, вывод на передний план.
- Добавлен диагностический режим `aspia_host --shell-test` (запуск оболочки без сессии).

## Быстрая поддержка (Quick Support)

- Экспорт из настроек хоста: один exe с адресом и ключом роутера, пользователями хоста
  (логин и пароль) и ID хоста внутри. Одноразовый пароль не экспортируется.
- Запуск **без прав администратора**: служба работает внутри процесса, окно — отдельный процесс
  того же файла. Данные хранятся в `%LOCALAPPDATA%\AspiaQS`.
- ID сохраняется между запусками. Если установленный хост работает, пакет получает новый ID, чтобы
  не конфликтовать с ним.
- Кнопка со щитом рядом с ID перезапускает пакет с правами администратора.
- Закрытие окна завершает работу пакета (в трей не сворачивается).
- Служебные ключи: `--export-quick-support=<файл>` и `--qs-info`.

## Клиент

- Чистка неактивных хостов: 1, 3 или 6 месяцев, по умолчанию выключена. Хосты без даты последнего
  подключения и хосты онлайн не удаляются. Перед удалением — подтверждение с количеством.
- Режим подключения из командной строки с опциями 2.x (`--address`, `--username`, `--password`,
  `--session-type`, `--router-address` и другие).
- Окно сессии, открытое из командной строки, выводится на передний план.
- Экспорт установщика с настройками хоста из окна настроек.
- Опция «Запомнить мастер-пароль»: ключ базы хранится в системном хранилище секретов, пароль
  спрашивается один раз.

## Экран и захват

- Список экранов хоста и просмотр всех мониторов сразу, режим «весь рабочий стол».
- Захват через Windows Graphics Capture, следование активной сессии пользователя.

## Установщик и сборка

- Установка обновляется поверх уже установленной версии, в том числе той же `3.0.37`.
- Издатель в установщике и автор форка в «О программе»: Paravis.
- Удалена поддержка Android.
- Сборки Windows x86/x64, macOS и Linux на hosted runners GitHub Actions.
- Свой сервер обновлений: адрес и публичный ключ.
- Новые строки переведены на все 24 языка интерфейса.
- Скрипт сборки умеет собирать только затронутые компоненты.
